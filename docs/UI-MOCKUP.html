Proposed integration: a Ruilhenn window styled through EllesmereUI.RegisterSkin, using its public shell, panel, button, tab and scrolling primitives. This mock-up approximates a dark EUI look with the default Retail teal accent; the game window would follow the user's EUI theme. Guardian and Feral keep independent shared templates and source characters. Key bindings currently use a single global backup; grouping them with spec templates needs a storage change. Existing backups have unknown source until saved again. Save overwrite and load replacement confirmations name the affected category and destination. Combat disables mutations while allowing browsing. Keyboard and controller access require in-game validation. No EUI assets are copied into this mock-up.
